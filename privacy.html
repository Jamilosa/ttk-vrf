Privacy Policy

Last Updated: July 20, 2026

1. Introduction

This privacy policy applies to the Unhinged_Amygdala automation application. This app is built strictly for personal, internal use to automate content posting to a specific TikTok account.

2. Data Collection

This application does not collect, store, or process personal data from public users. It only utilizes the authentication tokens provided by the developer to interface with the TikTok Content Posting API.

3. Data Usage

The authorization data is used solely to allow the application to publish content to the developer's owned TikTok account.

4. Contact

For any questions regarding this internal tool, please contact the developer directly.
